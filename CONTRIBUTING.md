# Contributing

Reproduce the behavior on a small corpus and include the claim, policy, budget and expected observation in an issue or pull request. Use synthetic text for regressions involving private sources. An anonymized failure can often be described using source IDs, integer score triples and the expected withdrawal decision.

Run the Python and browser suites locally before submitting a change. New decision rules need Python and browser parity coverage. Changes to a benchmark protocol, threshold or model identity define a separate experiment. Keep its artifacts distinct from the frozen release. [Reproduction guide](docs/reproduce.md)

The software uses the MIT license. Include provenance and reuse terms with any proposed data addition. [Third-party notices](THIRD_PARTY_NOTICES.md)
